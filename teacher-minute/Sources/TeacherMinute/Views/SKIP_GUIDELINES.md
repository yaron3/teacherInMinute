# Skip Framework Development Guidelines

## Overview
This project uses [Skip](https://skip.tools) to transpile Swift/SwiftUI code to Kotlin/Jetpack Compose for Android. This allows us to write once in Swift and deploy to both iOS and Android.

## Key Rules for Skip Compatibility

### 1. **Avoid `private` Access Modifiers in Bridged Code**

❌ **Don't do this:**
```swift
struct MyView: View {
    @State private var showDialog = false  // ❌ Skip has issues with private
    private func helper() { }  // ❌ May not bridge properly
}
```

✅ **Do this instead:**
```swift
struct MyView: View {
    @State var showDialog = false  // ✅ Internal (default) access
    func helper() { }  // ✅ Internal access
}

// Or if you need to limit visibility:
struct MyView: View {
    @State fileprivate var showDialog = false  // ✅ fileprivate works better
}
```

### 2. **Use Public for Reusable Components**

When creating reusable views or utilities that will be used across files:

```swift
#if !os(Android)
public struct PhotoSourceButton<Label: View>: View {
    let onImageData: (Data) -> Void
    @ViewBuilder var label: () -> Label
    
    @State var showDialog = false  // Not private!
    
    // Explicit public initializer
    public init(onImageData: @escaping (Data) -> Void, 
                @ViewBuilder label: @escaping () -> Label) {
        self.onImageData = onImageData
        self.label = label
    }
    
    public var body: some View {
        // ...
    }
}
#endif
```

### 3. **Platform-Specific Code Structure**

Always wrap platform-specific code in conditional compilation:

```swift
#if !os(Android)
    // iOS/macOS code
    PhotoSourceButton(onImageData: { data in
        processImage(data)
    }) {
        MyLabel()
    }
#else
    // Android code via Skip
    Button {
        showAndroidPhotoDialog = true
    } label: {
        MyLabel()
    }
    .confirmationDialog(...) { ... }
#endif
```

### 4. **State Properties**

```swift
// ✅ Good - Skip compatible
@State var isLoading = false
@State var userName = ""
@State var selectedItems: Set<String> = []

// ❌ Avoid
@State private var isLoading = false  // Skip may have issues
```

### 5. **Environment Properties**

```swift
// ✅ Good
@Environment(\.colorScheme) var colorScheme
@Environment(\.dismiss) var dismiss

// ❌ Avoid
@Environment(\.dismiss) private var dismiss
```

### 6. **Import Patterns**

```swift
import SwiftUI
#if !os(Android)
@preconcurrency import PhotosUI
#else
import SkipBridge
#endif
```

## Common Patterns in This Project

### Photo Picking
- **iOS/macOS**: Use `PhotoSourceButton` from `PhotoSourcePicker.swift`
- **Android**: Use `AndroidProfileImagePickerBridge` with confirmation dialog

### Localization
```swift
Text(LocalizationSupport.localized("Hello"))
.environment(\.locale, LocalizationSupport.locale(languagePreference: pref))
.environment(\.layoutDirection, LocalizationSupport.layoutDirection(languagePreference: pref))
```

### Theming
```swift
@Environment(\.colorScheme) var colorScheme
var theme: AppTheme {
    AppTheme(colorScheme: colorScheme)
}
```

### Icons
```swift
// Use PlatformIcon instead of Image(systemName:)
PlatformIcon(systemName: "camera.fill", size: 16, weight: .bold, color: .pink)
```

## When `private` is OK

`private` is acceptable for:
- Local helper functions that stay within a single file
- Computed properties not exposed to Skip
- Implementation details in `#if !os(Android)` blocks that never get bridged

```swift
struct HelperUtils {
    #if !os(Android)
    private static func iosOnlyHelper() -> String {
        // This is fine because it's iOS-only
    }
    #endif
}
```

## Debugging Skip Issues

If you encounter Skip compilation errors:

1. **Check for `private` keywords** in structs/classes that get bridged
2. **Verify `#if !os(Android)` blocks** are properly closed
3. **Look for missing public initializers** on public types
4. **Check that files are in the correct target** (both iOS and Skip targets if needed)

## Build Configuration

- iOS/macOS builds compile with standard Swift
- Android builds use Skip to transpile to Kotlin
- Bridge files (e.g., `ProfileView_Bridge.swift`) are auto-generated by Skip
